# THE MARSHANS — Asset Map & Directory Guide

This directory structure organizes all customer-facing and internal media assets for THE MARSHANS storefront.

```
public/assets/
├── branding/
│   ├── logo/          # Main wordmark and brand lockups (SVG, high-res PNG)
│   ├── favicon/       # Browser tab icons (favicon.png, favicon.ico, 32x32, 192x192)
│   └── marks/         # Emblems, crests, monogram marks
│
├── hero/
│   ├── home/          # Hero video and poster fallbacks
│   ├── campaigns/     # Seasonal or launch campaign video/imagery
│   ├── clouds/        # Atmospheric cloud layers & alpha cutouts
│   └── backgrounds/   # Stage and environment backdrop plates
│
├── carousel/
│   ├── home/          # Full-screen home poster carousel slides
│   ├── campaigns/     # Campaign-specific carousel banners
│   └── posters/       # High-resolution vertical & horizontal artwork
│
├── products/
│   ├── thumbnails/    # Catalog cards and grid thumbnail renders (1:1 / 4:5)
│   ├── gallery/       # Multi-angle product views
│   ├── detail/        # High-resolution closeups and material inspection
│   └── video/         # 360-degree rotation clips and turntable videos
│
├── categories/        # Universe and category cover imagery (Lumo, Fandom, MiniTales, etc.)
│
├── banners/           # Promo strips, announcement banners, editorial callouts
│
├── mascot/            # The Marshans mascot keyframes, badges, and expressions
│
├── icons/             # Custom UI icons, badges, material indicators
│
├── account/           # Customer portal illustrations, empty state graphics
│
├── custom-3d/
│   ├── hero/          # Studio intro graphic and 3D preview backdrop
│   ├── examples/      # Past custom prints and prototype showcases
│   └── illustrations/ # Explanatory step-by-step guides (upload -> print -> finish)
│
└── placeholders/      # Development fallbacks and SVG silhouettes
```
